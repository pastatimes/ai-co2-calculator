# AI CO2-calculator

Gratis webtool die de klimaatimpact van je AI-gebruik inzichtelijk maakt: geschatte uitstoot per dag, herkenbare vergelijkingen en groenere alternatieven.

**Probeer hem live:** [kimberleyvanruiven.nl/co2](https://www.kimberleyvanruiven.nl/co2)

## Stack en bronnen

- Next.js, Claude API
- Onderzoeksdata op basis van Luccioni et al. (2023) en het Mistral Environmental Report (2025)
